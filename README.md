
🛠️ Multi-Utility Toolkit
A command-line interface (CLI) Python application offering standard utilities for date/time calculations, math problems, random data generation, UUID creation, basic file I/O operations, and dynamic module attribute exploration.

🚀 Features
The toolkit includes six primary modules:

📅 1. Datetime & Time Operations
Current Date & Time: Display the formatted current timestamp.

Date Difference: Calculate the number of days between two dates (YYYY-MM-DD).

Custom Formatting: View formatted full calendar dates.

Stopwatch: Measure elapsed time between start and stop triggers.

Countdown Timer: Set dynamic time countdowns in seconds.

📐 2. Mathematical Operations
Factorials: Compute factorials for integer inputs.

Compound Interest: Calculate compound interest based on principal, rate, and time.

Trigonometry: Evaluate sin, cos, and tan values in degrees.

Geometric Area: Compute areas for circles and rectangles.

🎲 3. Random Data Generation
Random Numbers: Generate random integers within a custom range.

Random Lists: Generate lists of random integers.

Password Generator: Produce secure passwords containing letters, numbers, and special characters.

OTP Generator: Generate 6-digit One-Time Passwords.

🆔 4. Unique Identifiers (UUID)
UUIDv4 Generation: Quickly generate standard random Universally Unique Identifiers.

📁 5. File Operations
Create File: Generate new blank files.

Write File: Write fresh content/overwrites to target files.

Read File: Print stored text content with standard error-handling.

Append File: Append text lines to existing files.

🔍 6. Module Exploration (dir())
Inspect attributes dynamically for core imported modules (datetime, time, math, random, uuid).

🛠️ Requirements & Installation
Python Version: Python 3.x

Dependencies: Built entirely using Python Standard Libraries. No external third-party packages (pip install) required!

🏃 How to Run
Clone or Download the project file (e.g., main.py).

Open your terminal or command prompt in the directory containing the file.

Run the application:

Bash
python main.py
📋 Usage Overview
Upon running the program, the main interactive CLI menu displays:

Plaintext
===================================
Welcome to Multi-Utility Toolkit
===================================
Choose an option:
1. Datetime and Time Operations
2. Mathematical Operations
3. Random Data Generation
4. Generate Unique Identifiers (UUID)
5. File Operations (Custom Module)
6. Explore Module Attributes (dir())
7. Exit
===================================
Simply enter the corresponding number (1-7) to navigate through options and execute specific functionality.
